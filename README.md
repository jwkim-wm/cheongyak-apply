# 청약 알림 신청 페이지

청약 알림 봇의 **신청 창구**입니다. 관심 지역과 단지 규모를 고르면 그 조건이 담긴 텔레그램 링크가 만들어지고,
버튼 한 번으로 봇에 등록됩니다. 받는 사람은 설치할 것도, 만들 계정도 없습니다.

**신청 페이지** → <https://jwkim-wm.github.io/cheongyak-apply/>

알림을 보내는 쪽(수집·계산·발송)은 별도 저장소에 있습니다. 이 저장소는 화면 하나뿐입니다.

---

## 어떻게 동작하나

```
사용자가 지역·규모 선택
        ↓
https://t.me/<봇아이디>?start=v1_300_ic-ggn
        ↓
텔레그램에서 '시작' → 봇이 /start v1_300_ic-ggn 수신
        ↓
봇이 조건을 해석해 구독자로 등록
```

텔레그램 딥링크의 `start` 값에는 **영문·숫자·`_`·`-` 만** 들어갈 수 있습니다.
그래서 한글 지역명을 그대로 못 싣고 코드로 주고받습니다.

### 조건값 형식

```
v1_300_ic-ggn
│  │   └── 지역 코드, 여러 개는 '-' 로 연결 (ic=인천, ggn=경기북부)
│  └────── 최소 세대수 (0 = 제한 없음)
└───────── 형식 버전
```

전국은 `all` 한 개로 보냅니다 — `v1_1000_all`.

### 지역 코드

| 코드 | 지역 | 코드 | 지역 | 코드 | 지역 |
|---|---|---|---|---|---|
| `all` | 전국 | `dg` | 대구 | `cb` | 충북 |
| `se` | 서울 | `gj` | 광주 | `cn` | 충남 |
| `ic` | 인천 | `dj` | 대전 | `jb` | 전북 |
| `ggn` | 경기북부 | `us` | 울산 | `jn` | 전남 |
| `ggs` | 경기남부 | `sj` | 세종 | `gb` | 경북 |
| `bs` | 부산 | `gw` | 강원 | `gm` | 경남 |
|  |  |  |  | `jj` | 제주 |

이 표는 봇 저장소의 `src/regions.py` 와 **짝을 이룹니다.** 한쪽만 고치면 신청이 해석되지 않습니다.

## 내 것으로 띄우기

터미널 없이 브라우저만으로 됩니다.

1. 이 저장소를 **Fork** 합니다
2. `index.html` 을 열고 연필 아이콘 → 파일 위쪽의 봇 아이디를 내 봇으로 바꿉니다

   ```js
   var BOT_ID = "cheongyak_alarm_bot";   // ← 따옴표 안만 교체 (@ 없이)
   ```

3. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save
4. 1~2분 뒤 `https://<내아이디>.github.io/cheongyak-apply/` 에서 열립니다

봇 아이디를 넣어두면 페이지 하단의 `관리자 설정`은 자동으로 숨겨집니다.
아이디 없이 링크만 공유하고 싶다면 주소 뒤에 `?bot=<봇아이디>` 를 붙여도 됩니다.

## 보안

이 저장소는 **공개입니다.** 그래서 다음만 들어 있습니다.

- 봇의 **공개 아이디** (텔레그램에서 누구나 검색할 수 있는 값)

들어 있지 않은 것:

- 봇 토큰, 공공데이터 인증키 — 비공개 저장소의 암호화된 비밀값에만 둡니다
- 신청자 명단, chat_id 등 개인정보 — 이 페이지는 아무것도 저장하지 않습니다

페이지는 서버 없이 도는 정적 HTML 한 장이고, 외부로 보내는 요청도 없습니다.
선택한 조건은 텔레그램 링크를 만드는 데만 쓰입니다.

---

## 파일

```
index.html    신청 페이지 전부 (HTML·CSS·JS 한 파일)
```

의존성도, 빌드 단계도 없습니다. 파일을 열면 그대로 동작합니다.

### 화면 구성

| 영역 | 내용 |
|---|---|
| 1. 지역 선택 | 전국 또는 시·도 단위 중복 선택 |
| 2. 규모 선택 | 제한 없음 / 300 / 500 / 1,000세대 이상 |
| 요약 + 버튼 | 고른 조건을 문장으로 확인하고 텔레그램으로 이동 |
| 복사용 명령어 | `시작` 버튼이 안 뜨는 경우(기존 대화 이력 보유자)의 대안 |

마지막 항목이 중요합니다. 텔레그램은 **그 봇과 처음 대화할 때만** `시작` 버튼을 띄웁니다.
예전에 대화한 적이 있으면 링크를 눌러도 아무것도 전송되지 않으므로,
페이지가 `/start v1_300_ic-ggn` 을 복사 버튼과 함께 띄워 대화창에 붙여넣도록 안내합니다.

## 알아둘 점

- 알림은 참고용입니다. 실제 청약은 반드시 입주자모집공고문을 확인해야 합니다.
- 텔레그램 앱이 설치돼 있어야 알림을 받을 수 있습니다.
